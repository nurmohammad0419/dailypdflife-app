About HTML to PDF

Email templates, saved web pages, reports exported from systems and simple notes are often HTML files. HTML to PDF shows a preview of your file or pasted content and saves it as a PDF with the page size and margins you choose. Styles inside the HTML are kept, so headings, colours and tables look right.

How to convert HTML to PDF

  1. Upload an .html file, or paste HTML code or plain text.
  2. Check the preview.
  3. Choose the page size and margins.
  4. Tap Save as PDF. In the print window, choose Save as PDF and tick Background graphics.

Safety and limits

For your safety, scripts and embedded frames in the HTML are removed and never run. Pictures appear only when they use full web addresses (starting with https://) or are embedded in the file. To save a live website as a PDF, open it in your browser and use Print → Save as PDF. For Word documents use Word to PDF.

Frequently asked questions

Can I convert a website address?

Open the site in your browser and use Print → Save as PDF; browsers don't let other pages load a site for you.

Why are my images missing?

Images with relative paths can't be found. Use full https:// addresses.

Will JavaScript run?

No, scripts are removed for safety.

Is my content uploaded?

No.
