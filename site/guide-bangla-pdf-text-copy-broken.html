You find the Bangla text you need in a PDF, such as a government notice, an exam result, a book chapter or a form, but when you copy and paste it, it turns into nonsense: English letters like Avgvi †mvbvi evsjv, or Bangla letters in the wrong order with broken conjuncts (যুক্তাক্ষর). This is a very common problem, and it has two main causes.

Cause 1: The PDF was made with a Bijoy (ANSI) font

For many years, most Bangla typing in Bangladesh used the Bijoy keyboard with fonts such as SutonnyMJ. These fonts don't use Unicode, the international standard for text. Instead they draw Bangla shapes on top of ordinary English character codes. On screen the text looks perfectly Bangla, but the real characters underneath are English letters and symbols. When you copy it, you get the English codes, which is why “আমার সোনার বাংলা” pastes as something like Avgvi †mvbvi evsjv.

How to tell: if the pasted text is mostly English letters and symbols such as †, ‡ and Ô, it's Bijoy text.

Fix: paste the gibberish into a Bijoy-to-Unicode converter, such as the converter built into the Avro Keyboard software or one of the many free online converters. The output is proper Unicode Bangla you can use anywhere.

Cause 2: The PDF lost the link between shapes and letters

Bangla is a complex script: a single shape on screen can be several letters joined together, and some vowel signs are drawn before the consonant they follow. When a PDF is created, the program should store a map that says which letters make up each shape. Some programs and printers save the shapes without a proper map. The PDF looks fine but copying gives missing letters, wrong order or boxes.

How to tell: the pasted text is Bangla but with jumbled vowel signs, missing conjuncts or empty boxes.

Fix: use OCR, which reads the text from the picture of the page instead of from the broken map.

  1. Open OCR and choose the PDF, or a screenshot of the part you need.
  2. Select Bangla as the language.
  3. Tap Extract text, then copy it or download it as a Word file.
  4. Read it through and correct any mistakes. OCR is very good on clear printed text, but conjuncts and small print can sometimes be misread.

Scanned PDFs

If the PDF is a scan of paper, there is no text in it at all, only pictures, so nothing can be copied. OCR is the only way to get the text. For the best results, scan with good light and straight pages using Scan to PDF before running OCR.

Making Bangla PDFs that copy correctly

If you create documents yourself, type with a Unicode keyboard (Avro in Unicode mode, Google Input Tools or the phone's Bangla keyboard) and a Unicode font such as Kalpurush, SolaimanLipi, Nikosh or Noto Sans Bengali. Save to PDF from Word, Google Docs or LibreOffice. DailyPdfLife's PDF editor, Word to PDF and CV maker all handle Unicode Bangla, so the text in your PDF stays real, searchable Bangla that others can copy.
